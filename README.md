# Tower of Elrhun

Unreal Engine **5.8** C++ project. Open `IsekaiVillage.uproject`.

The project filename and C++ module retain their original names. The current starting map is `Map_ElRuhnSky`.

The first staffed village loop is available: place a home and general shop, let the golem walk to work, sell wood with T or buy with Y, and save with F5. Use B for construction, the wheel or Page Up/Page Down to choose, R to rotate, and T or left click to place. See [village loop and verification](Docs/VILLAGE_GOLEM_LOOP.md).
